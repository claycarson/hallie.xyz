# Device check (iPad)

Nothing to check on the iPad yet: there is no HTTPS dev URL (PLAN §2.5 needs the name and a DNS
record). On the Mac, from `games/nail-salon/`:

    npm run serve

then open http://127.0.0.1:8813/?debug and paint with the mouse.

Useful URLs: `?scene=nail|hand`, `&theme=boutique|candy|midnight`,
`&shape=round|square|squoval|oval|almond|coffin|stiletto`, `&free=0…1`, `&flip=1`, `&polish=cream-pink`.
